PPSSPP Web

Controls

Keyboard: PPSSPP's default layout.

Arrow keysD-pad
I / J / K / LAnalog stick up / left / down / right
Z / X / A / SCross / Circle / Square / Triangle
Q / WL / R
Space / EnterStart / Select
EscPause menu
Tab (hold)Fast forward
F2Show or hide the stats overlay

DualShock 4 / DualSense (USB or Bluetooth, in Chrome or Edge): face buttons, D-pad and left stick map one to one; L1 / R1 are L / R; Options is Start, Share / Create is Select; the PS button or L2 opens the pause menu. Press any button once after connecting so the browser exposes the pad. Remap in Settings → Controls.
